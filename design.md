# sork. landing page design direction

## Intent

The landing page is dark, quiet, and precise. It should feel like an invitation to look closer at everyday food—not like a dashboard, laboratory console, or sustainability scorecard.

## Visual system

- Background: near-black green graphite (`#0a0d0b`).
- Surfaces: subtle green-black (`#101411`), separated by fine graphite borders.
- Primary text: soft off-white (`#f4f5ef`).
- Secondary text: restrained grey-green (`#a4aaa4`).
- Accent: fresh signal green (`#c9ff5b`) used sparingly for emphasis and actions.
- Type: system sans-serif with tight display tracking, compact interface labels, and monospaced sequence numbers.
- Geometry: 9–18px corner radii, one-pixel borders, open layouts, generous vertical rhythm.

## Component reference

The components borrow the interaction character of [Beautiful UI](https://www.beautifului.dev/): compact controls, fine borders, low-contrast surfaces, concise labels, and simple motion. This is a visual reference only; no Beautiful UI source code is copied.

## Boundaries

- No dashboard, data table, product search workflow, scorecard, map, chart, or product fixtures in Phase 1.
- No gradients, decorative metrics, badges, or mock data.
- The landing CTA explains the future product journey and scrolls within the landing page.
